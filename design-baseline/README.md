# Design Baseline Library

Canonical visual baseline artifacts for Learn shared components.

Required structure per component:

```
design-baseline/
  JourneyHero/
    before.png
    after.png
    desktop.png
    tablet.png
    mobile.png
    notes.md
  ContinueCard/
  JourneyCard/
  SectionHeader/
  AchievementCard/
```

Rules:

- Capture desktop/tablet/mobile for every changed shared component.
- Include before/after when polishing.
- Keep notes concise; reference capability + VC-001 report.
- VC-001 and capability verification fail if required artifacts are missing.
